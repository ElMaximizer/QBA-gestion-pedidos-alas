# Historias de usuario vigentes

Lista indicada por el usuario para organizar el trabajo por HU. Esta numeración
y estos objetivos son la referencia del proyecto; las ramas históricas y los
nombres antiguos del código no cambian su alcance.

## Administrador

### HU01 — Registrar un pedido
Como administrador, quiero registrar pedidos con varios productos para mantener organizada la información de cada cliente.

### HU02 — Modificar un pedido
Como administrador, quiero poder modificar el estado del pedido para mantener actualizada la información y saber en qué etapa se encuentra cada pedido.

### HU03 — Cancelar un pedido
Como administrador, quiero cancelar un pedido cuando corresponda para mantener actualizado el registro y conservar su historial.

### HU04 — Consultar pedidos
Como administrador, quiero consultar los pedidos realizados para saber qué pedidos están pendientes, cuáles se están preparando y cuáles ya fueron entregados.

### HU05 — Registrar pagos y confirmar transferencias
Como administrador, quiero registrar el método y el estado del pago de cada pedido y confirmar las transferencias recibidas y saber cuándo el pedido está pago.

### HU06 — Administrar productos
Como administrador, quiero agregar, modificar o eliminar productos para mantener actualizado el catálogo de la panadería.

### HU07 — Controlar el stock
Como administrador, quiero consultar y actualizar el stock de materias primas para saber qué productos hay disponibles y qué materiales necesitan reponerse.

### HU08 — Consultar ventas
Como administrador, quiero consultar las ventas realizadas para llevar un mejor control de la panadería.

### HU09 — Registrar entregas de mercadería
Como administrador, quiero registrar la mercadería recibida de los proveedores para mantener actualizado el stock de materias primas.

### HU10 — Administrar empleados
Como administrador, quiero consultar las cuentas de los empleados y las tareas que realizan para llevar un control del personal que utiliza el sistema.

## Empleado

### HU11 — Registrar pedidos
Como empleado, quiero registrar los pedidos de los clientes para evitar depender de las anotaciones en papel.

### HU12 — Consultar pedidos
Como empleado, quiero consultar los pedidos para saber qué productos hay que preparar y para qué fecha.

### HU13 — Actualizar el estado de un pedido
Como empleado, quiero actualizar el estado de un pedido a pendiente, en preparación, listo o entregado para que todos conozcan su situación.

### HU14 — Consultar productos
Como empleado, quiero consultar los productos disponibles para poder informar correctamente a los clientes.

### HU15 — Registrar entregas
Como empleado, quiero registrar las entregas de los pedidos para dejar constancia de que fueron entregados.

## Cliente

### HU16 — Registrarse
Como cliente, quiero crear una cuenta para poder utilizar la página de la panadería y realizar pedidos.

### HU17 — Iniciar sesión
Como cliente, quiero iniciar sesión con mi usuario y contraseña para acceder a mi cuenta y consultar mis pedidos.

### HU18 — Realizar un pedido
Como cliente, quiero realizar un pedido desde la página web, elegir retiro o delivery y poder pagar el total por transferencia, para completar mi compra sin ir personalmente a la panadería.

### HU19 — Consultar el estado de mi pedido
Como cliente, quiero consultar el estado de mi pedido para saber si está pendiente, en preparación o entregado.

### HU20 — Ver mis pedidos
Como cliente, quiero consultar mis pedidos anteriores y actuales para tener un registro de lo que solicité.

## Jefe / Dueño

### HU21 — Administrar empleados
Como dueño de la panadería, quiero crear y desactivar cuentas de empleados para controlar quién tiene acceso al sistema.

### HU22 — Administrar usuarios y permisos
Como dueño de la panadería, quiero decidir qué puede hacer cada usuario para proteger la información y evitar que alguien modifique datos que no le corresponden.

### HU23 — Administrar pedidos
Como dueño de la panadería, quiero consultar y modificar los pedidos de cualquier cliente para supervisar la gestión de la panadería.

### HU24 — Consultar las ventas
Como dueño de la panadería, quiero consultar las ventas por período para conocer el funcionamiento del negocio.
